## Security

| Finding | Fix |
| --- | --- |
| Unbounded `sf` stdout (and jq pipelines over it) | `capped_stdout` + `sf_try`: `head -c` cap (`BLUECHIP_SF_MAX_BYTES`, default 1 MiB), GNU `timeout` (`BLUECHIP_SF_TIMEOUT`, 60s). Oversize → structured `TRANSIENT`. stderr discarded, never persisted. |
| `cat` / `.read()` without a ceiling | `read_capped_file` for snapshot + `hygiene.json`. Clipboard ingest `head -c CLIP_MAX`. Event Log Python `fh.read(max_bytes+1)` (`OFFENDERS_MAX_BYTES`). MCP stdout/stderr and Content-Length/readline capped at 1 MiB. Apex log bodies already `LOG_MAX_BYTES`. |
| `write_secure` used `$path.tmp.$$` + `cat >` (symlink / PID race) | `mktemp` (O_EXCL) in the dest dir, `chmod 600`, `mv -f`. Refuse if dest or parent is a symlink. State/cache dirs `umask 077` + `0700`. |
| `notify-send` interpolated untrusted title/body; no `--` | `notify_send_safe`: neutralize, argv array, `/usr/bin` or `/bin` only, `PATH` pinned for that spawn, `--` before title/body. Clipboard helper toasts **only after success**. |
| `xdg-open` / copy helpers | `safe_xdg_open` + `path_is_unsafe`: refuse `://` and leading `-`; argv + `--`. |
| Clipboard ingest of URLs / flag-shaped strings | `clipboard_ingest_ok` refuses empty, `://`, leading `-`, CR/LF. Neutralize remains on the token. |
| PATH / cwd impostor `sf` | Resolve `BLUECHIP_SF`/`sf` to an absolute path at startup. Do **not** globally pin `PATH` (node-based `sf` needs nvm). Helpers use `pinned_cmd`. Tests prove an absolute stub beats a cwd `sf`. |
| MCP tool args interpolated into a shell | Still `subprocess.run([list])`. Org alias, FLS user/fields, offenders `--since` allowlisted. Timeout + output size limits. Display-only; no write tools. |
| SOQL / hygiene.json fragments | Existing API-name + filter allowlist kept. Config file read is now size-capped. |
| Secrets in output / cache | Snapshot still `del(.accessToken, .password, .clientSecret, .clientId)`. Named Creds never `SELECT ParameterValue` (grep-proven). `redact_secrets_json` on JSON packs. Log bodies still drop Authorization/password lines. Fixtures keep leak canaries for tests only. |

## Performance

| Finding | Fix |
| --- | --- |
| `bar --all` ran `compute_desk` twice (tooltip + JSON) | One desk pulse; tooltip renders from that blob. |
| Desk pulse issued an extra FlowInterview COUNT per org | Use snapshot `.faults` (already fetched in `build_snapshot`). Idle `bar` is still one cached snapshot. `--all` / `desk` stay opt-in. |
| Redundant `sf org display` on every bar tick | Unchanged TTL (`BLUECHIP_CACHE_TTL`, 120s). Test: second `bar` without `--refresh` records zero `org display` calls. |
| Hygiene workers unbounded + possible orphans | Concurrency cap `BLUECHIP_HYGIENE_JOBS` (default 4, max 8). `wait -n` (fallback `wait`). RETURN trap kills leftover jobs and removes the temp dir. |
| `watch 0` / `logs --follow` busy-loop | Watch interval clamped to `BLUECHIP_WATCH_MIN` (5s). Follow backoff 2→16s on errors; 2s on success. |
